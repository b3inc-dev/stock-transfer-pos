（91 characters）

## 4. App details (≤500)

```
Send stock from one store or warehouse on POS and confirm it when it arrives. Scan barcodes or search products to build each list, so there is no paper slip to copy.

On POS, staff start transfers, receiving, losses, stock counts, purchases, orders and adjustments from tiles. When receiving, compare expected and actual quantities and record any gap.

In admin, filter history and export it to CSV. Transfers use Shopify inventory transfers and shipments, so stock matches Shopify admin.
```
（488 characters。空白と改行も数えた。上限 500 に近いので、貼ったときに入力欄の数で確かめる）

## 5. Key benefits

1. Finish every stock move on POS — both the sending and the receiving store confirm on the spot.
2. Catch counting mistakes — see expected and received quantities side by side.
3. Stay in sync with Shopify — uses Shopify inventory transfers, shipments and quantities.
4. Trace every move — see when, where and how much stock moved, and export to CSV.
