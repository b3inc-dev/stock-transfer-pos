# パートナーで「価格」を設定する手順（今回のアプリ用）

公開アプリの **Lite / Pro** プランで、パートナーダッシュボードから価格を設定するときの具体的な手順です。

---

## 前提

- **Managed pricing** を使う場合、パートナー画面でプランと料金を設定します。
- アプリ側は「サブスクリプションの**名前**に "Lite" または "Pro" が含まれるか」でプランを判定しています。  
  → パートナーで設定する**プランの表示名**に、必ず **Lite** と **Pro** を含めてください。

---

## 1. どこを開くか

1. **Shopify パートナーダッシュボード**（https://partners.shopify.com）にログイン
2. 左メニュー **「Apps」** → **対象アプリ**をクリック
3. 左サイドバー **「配布」**（Distribution）を開く
4. **「価格」**（Pricing）または **Pricing content** → **Manage** を開き、価格一覧（Public plans）の画面へ

※ 表示が英語の場合は **Distribution** → **Pricing** です。

---

## 2. Managed pricing を選ぶ

- 価格の方式で **「Managed pricing」** を選択
- すでに Billing API で課金を作成している場合は、Managed に切り替える前に**既存の課金を解消**する必要がある場合があります

---

## 3. プランを 2 つ追加する（Lite / Pro）

公開プランは**最大 4 つ**まで。今回の構成では **Lite** と **Pro** の 2 つを追加します。

### 3.1 1 つ目：Lite プラン

**「Public plans」** → **「Add」**（追加）をクリックし、次のように入力します。

| 項目 | 入力する値 |
|------|------------|
| **内部計画ハンドル**（Plan handle） | `lite` または `lite_monthly`（30文字以内・後から変更不可。英小文字・数字・アンダースコア） |
| **請求する**（Billing） | **「毎月の継続払い」**（Monthly） |
| **月額料金**（Monthly charge） | 例: `40`（USD）。設計書の例では $40/月（10ロケーションまで） |
| **年間料金** | 月額のみなら `0` のまま |
| **無料トライアル期間**（Free trial） | `7`（7日間） |
| **リダイレクトURL**（Redirect URL） | `/app` または `/app/settings`（ドメインは不要） |

**Save** で保存します。

### 3.2 2 つ目：Pro プラン

もう一度 **「Add」** で 2 つ目のプランを追加します。

| 項目 | 入力する値 |
|------|------------|
| **内部計画ハンドル** | `pro` または `pro_monthly` |
| **請求する** | **「毎月の継続払い」**（Monthly） |
| **月額料金** | 例: `120`（USD）。設計書の例では $120/月（10ロケーションまで） |
| **年間料金** | 月額のみなら `0` |
| **無料トライアル期間** | `14`（14日間） |
| **リダイレクトURL** | `/app` または `/app/settings` |

**Save** で保存します。

---

## 4. プランの「表示名」を必ず設定する（重要）

アプリは**サブスクリプション名**に "Lite" / "Pro" が含まれるかでプランを判定します。  
パートナーで設定する**表示名**（Display name）に、必ず次のように含めてください。

1. 追加した各プランを選択し、**表示名・特徴**（または言語ごとの編集）を開く
2. **表示名**（Display name）を次のどちらかにする：
   - Lite プラン → **「Lite」** または **「Lite（7日間トライアル）」** など **Lite** を含む名前
   - Pro プラン → **「Pro」** または **「Pro（14日間トライアル）」** など **Pro** を含む名前
3. **特徴**（Top features）には、そのプランで使える機能を短く入力（例: 出庫・入庫・履歴・CSV）
4. 日本語・英語など、公開する言語ごとに **Edit** して同じように表示名を設定
5. **Save** で保存

※ 表示名に "Lite" / "Pro" が入っていないと、アプリ側でプランが正しく判定されず、機能制限が効かない・または逆に制限されすぎる原因になります。

---

## 5. 料金の目安（参考）

設計書・コード上の目安は次のとおりです。パートナーでは同じ値でも、少し変えても構いません。

| プラン | 月額（USD）目安 | トライアル | 備考 |
|--------|-----------------|------------|------|
| Lite   | $40             | 7日        | 10ロケーションまで。超えた分はアプリ側で Usage 報告の実装あり |
| Pro    | $120            | 14日       | 同上 |

※ 10ロケーション超の従量課金は、Managed pricing の「月額」とは別に、アプリ側の Billing API（Usage）で報告している場合はそのまま運用できます。Managed で設定するのは「基本の月額」と「トライアル日数」です。

---

## 6. 環境変数（SHOPIFY_APP_HANDLE）

アプリ内の「料金プラン」ページから、Shopify のプラン選択ページへ飛ぶ URL を組み立てるために、**SHOPIFY_APP_HANDLE** を使っています。

- **設定場所**: Render など、アプリのバックエンドの環境変数
- **値**: パートナーダッシュボードの **アプリのハンドル**（URL や設定画面に表示される英数字の識別子）
- 未設定の場合は `app` が使われます。本番ではパートナーで確認したハンドルを設定してください。

---

## 7. まとめチェックリスト

- [ ] パートナー → Apps → 対象アプリ → 配布 → 価格 を開いた
- [ ] Managed pricing を選択した
- [ ] 公開プランを 2 つ追加した（Lite・Pro）
- [ ] 各プランの**表示名**に **Lite** / **Pro** を含めた
- [ ] 月額・トライアル日数（Lite 7日・Pro 14日）を設定した
- [ ] リダイレクトURL を `/app` または `/app/settings` にした
- [ ] 本番環境に SHOPIFY_APP_HANDLE を設定した（必要なら）

より詳しい考え方・無料プランの例・複数プラン例は **docs/APP_PRICING_SETUP_GUIDE.md** を参照してください。

## 別案：Lite/Pro それぞれ「3ロケーション」「10ロケーション」「10以上従量」で分ける場合

Lite を「3ロケーション用」「10ロケーション用」、Pro も同様に分け、**10ロケーション超は従量課金**にしたい場合は、次のようにします。

### 制約

- パートナーでは **公開プランは最大 4 つ**までしか追加できません。
- そのため **「10ロケーション以上」専用のプラン**は作りません。10超分は、アプリ側の **Usage（従量）課金**で報告します。

### 4 プランの構成

| # | プラン（表示名の例） | 内部ハンドル例 | 月額（USD）例 | トライアル | 備考 |
|---|----------------------|----------------|---------------|------------|------|
| 1 | **Lite - 3ロケーション** | `lite-3` | 例: 20 | 7日 | 3ロケーションまで |
| 2 | **Lite - 10ロケーション** | `lite-10` | 例: 40 | 7日 | 10ロケーションまで。11以上は従量をアプリで報告 |
| 3 | **Pro - 3ロケーション** | `pro-3` | 例: 60 | 14日 | 3ロケーションまで |
| 4 | **Pro - 10ロケーション** | `pro-10` | 例: 120 | 14日 | 10ロケーションまで。11以上は従量をアプリで報告 |

※ 内部ハンドルはパートナー画面でアンダースコアが使えない場合は **ハイフン**（`lite-3` など）でよい。アプリはハンドルではなく**表示名**に含まれる "Lite"/"Pro" で判定するため、コードの変更は不要。

**ロケーション数とプランの一致チェック**: 表示名に **「3」または「10」**（例: 「Lite - 3ロケーション」「Lite - 10 locations」や `lite-3` / `lite-10`）が含まれる場合、アプリは「3ロケーション用」「10ロケーション用」を判定します。実際のロケーション数がプランを超えていると、プラン変更の案内が表示され、変更まで設定・在庫・入出庫などの機能は利用できません。

### パートナーでの設定手順（4プラン）

1. **配布 → 価格** で **Managed pricing** を選択。
2. **Public plans** で **Add** を 4 回使い、上表の 4 プランを 1 つずつ追加する。
3. 各プランで入力する内容の目安：

| 項目 | 1. Lite 3 | 2. Lite 10 | 3. Pro 3 | 4. Pro 10 |
|------|-----------|------------|----------|-----------|
| **内部計画ハンドル** | `lite-3` | `lite-10` | `pro-3` | `pro-10` |
| **請求する** | 毎月の継続払い | 毎月の継続払い | 毎月の継続払い | 毎月の継続払い |
| **月額料金**（USD） | 例: 20 | 例: 40 | 例: 60 | 例: 120 |
| **無料トライアル** | 7 | 7 | 14 | 14 |
| **リダイレクトURL** | `/app` または `/app/settings` | 同上 | 同上 | 同上 |

4. **表示名**は、アプリが Lite/Pro を判定するため、必ず **Lite** または **Pro** を含めます。
   - 例: 「Lite - 3ロケーション」「Lite - 10ロケーション」「Pro - 3ロケーション」「Pro - 10ロケーション」
   - 英語: "Lite - 3 locations", "Lite - 10 locations", "Pro - 3 locations", "Pro - 10 locations"

5. 保存後、公開する言語ごとに表示名・特徴を編集して **Save**。

### 10ロケーション「以上」の課金

- マーチャントが **Lite - 10ロケーション** または **Pro - 10ロケーション** を選択し、かつストアのロケーション数が **11以上** のとき、アプリ側で **Billing API の Usage（従量）** を報告します（既存の `reportUsageRecord` など）。
- パートナーには「10以上用」のプランは作らず、**同じ「10ロケーション」プラン ＋ アプリからの従量報告**で対応します。

### アプリ側の挙動（現状）

- プラン判定は **サブスクリプション名に "Lite" / "Pro" が含まれるか** で行っています。
- 上記のように表示名に「Lite」「Pro」を含めておけば、4 プランとも現状のまま **Lite** または **Pro** として認識され、機能制限（Lite は出庫・入庫・履歴など、Pro は全機能）はそのまま動きます。
- 3ロケーション用と10ロケーション用で**表示上の違い**（例：料金プラン画面で「3 loc プラン」「10 loc プラン」と出し分ける）をしたい場合は、サブスク名やプランハンドルを取得する実装を追加する必要があります。必須ではありません。

---

## 補足：Managed pricing を使う場合のアプリ側

価格を**パートナーでだけ**管理したい（Managed pricing）場合は、マーチャントが「このプランを選択する」を押したときに **Shopify のプラン選択ページ**（`https://admin.shopify.com/store/{ストア}/charges/{アプリハンドル}/pricing_plans`）へ**遷移**させる形にします。アプリはすでにこの URL を `pricingPlansUrl` として持っています。

- **現在の実装**: ボタンが form の POST でアプリの action を呼び出し、Billing API の `appSubscriptionCreate` で課金を作成しています。
- **Managed に合わせる場合**: 「このプランを選択する」を **リンク**（`<a href={pricingPlansUrl}>` など）に変更し、上記 URL を開くようにすると、パートナーで設定したプラン・料金・トライアルがそのまま使われます。そのときは `createAppSubscription` は呼びません。
