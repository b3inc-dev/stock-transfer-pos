# Stock Transfer POS 利用者ヘルプ

関連要件 #48。サイト側の対応パスは /help/stock-transfer-pos/ 。

## 導入・通常操作・例外
- 初期設定では利用条件、必要な権限、動作確認方法を記録する。
- 通常操作の対象は「出庫から受領まで、店舗間で動く商品を追う。」。導入者視点の手順と期待される結果を合成データで確認する。
- 症状別の初稿「入庫数が合わない・受領結果が分からない」
  1. 対象の出荷と入庫先を特定し、予定数・現物数・受領済み数を並べます。
  2. 通信が途切れたら、同じ受領を再確定する前に出荷の最新状態を確認します。予定10点のうち4点が受領済みなら、予定の残りは6点です。
  3. 受領履歴と入庫先の在庫変動を照合します。結果が分からない間は再確定を保留します。

## 変更時の確認
画面や手順の変更時は、アプリの変更PRから該当するサイト記事の差分を参照する。対象版、実際の画面名、操作結果、再試行可否を確認した上で案内する。上記は初稿であり実機確認済みの手順ではない。
