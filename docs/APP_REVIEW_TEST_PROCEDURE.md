# アプリ審査用：テスト手順の詳細

**目的**: Shopify App Store 審査の「アプリテスト情報：テスト手順」に記載するための、**詳細な手順書**です。  
審査担当者が同じ操作で再現できるよう、画面名・メニュー名・操作内容を具体的に記載しています。

---

## 1. 事前に用意するもの（審査側に伝える内容）

| 項目 | 記載例 |
|------|--------|
| **デモストアのURL** | `https://（デモ用ストア名）-dev.myshopify.com` など |
| **テスト用認証情報** | 管理者としてログインできるメールアドレス・パスワード（別途安全な方法で共有） |
| **補足** | 「インストール後、初回のみ管理画面でアプリを1回開いてから POS をご利用ください」 |
| **デモストアの準備** | ロケーション2つ以上、テスト用商品、仕入先マスタ1件以上。棚卸・調整を試す場合は棚卸の商品グループ作成が可能な状態。 |

---

## 2. テスト手順（詳細・日本語）

以下を**番号のとおりに**実行すると、アプリの基本動作を確認できます。

---

### ステップ 1：デモストアにログインする

1. ブラウザでデモストアの管理画面URLを開く。  
   （例: `https://（ストア名）-dev.myshopify.com/admin`）
2. テスト用の**管理者アカウント**（メール・パスワード）でログインする。
3. 管理画面のホームまたはダッシュボードが表示されることを確認する。

---

### ステップ 2：管理画面でアプリを開き、認証する（初回のみ）

1. 左サイドバーの **「アプリ」**（Apps）をクリックする。
2. アプリ一覧から **本アプリの名前**（例: POS Stock / 在庫出庫入庫アプリ）をクリックする。
3. **初回のみ**、Shopify の権限許可画面が表示される場合がある。  
   **「許可する」**（Install app / Approve）をクリックして認証を完了する。
4. アプリの画面が開き、左ナビに **「設定」「在庫情報」「入出庫」「仕入」「ロス」「発注」「棚卸」「調整」** などのメニューが表示されることを確認する。
5. **「設定」** をクリックし、設定画面（店舗設定・出庫設定などのタブ）が表示されることを確認する。  
   ※ ここで1回アプリを開くことで、後から POS から利用した際のデータ連携が正しく動作します。

---

### ステップ 3：POS を開く

1. 左サイドバーの **「POS」**（Point of Sale）をクリックする。
2. **「POS アプリ」**（POS apps）または **「アプリ」** セクションを開く。
3. 在庫処理用のタイルが一覧表示されることを確認する。  
   表示されるタイルの例：
   - **出庫 / 在庫処理**
   - **入庫 / 在庫処理**
   - **ロス / 在庫調整**
   - **棚卸 / 在庫調整**
   - **仕入 / 在庫処理**
   - **発注 / 在庫調整**
   - **調整 / 在庫調整**（簡易棚卸）

---

### ステップ 4-A：出庫を1件登録する（推奨フロー）

1. **「出庫 / 在庫処理」** タイルをタップ（クリック）する。
2. **コンディション画面**が開く。  
   - **出庫元**：在庫があるロケーションを1つ選択する。  
   - **宛先（入庫先）**：別のロケーションを1つ選択する。  
   （ロケーションが1つしかない場合は、テスト用に同じロケーションを両方に選んでも動作確認は可能です。）
3. **「商品リスト」** または **「次へ」** などで商品リスト画面に進む。
4. **検索** または **バーコードスキャン** で商品を1件追加する。  
   数量は **1** のままでよい。
5. 画面下部の **「確定する」** ボタンをクリックする。
6. 確認ダイアログが出た場合は **「確定」** を選択する。
7. 処理が完了し、モーダルが閉じるか、完了メッセージが表示されることを確認する。

---

### ステップ 5：管理画面で入出庫履歴を確認する

1. ブラウザで **管理画面** に戻る。  
   （別タブで開いている場合はそのタブへ。閉じている場合はストアの `/admin` から再度「アプリ」→ 本アプリを開く。）
2. アプリの左ナビで **「入出庫」** をクリックする。
3. **入出庫履歴** の一覧が表示される。
4. **いちばん上** または **直近の日付** に、先ほど POS で登録した **出庫** の1件が表示されることを確認する。
5. その行をクリックすると、**モーダル**で詳細（出庫元・宛先・商品明細・ステータスなど）が表示されることを確認する。

---

### ステップ 6：入庫を1件登録する

1. 左メニュー **「POS」** → **「POSアプリ」** を開く。
2. **「入庫 / 在庫処理」** タイルをタップする。
3. **入庫一覧**（未受領の Transfer 一覧）が表示される。  
   先ほど登録した **出庫** に対応する入庫が一覧に出ているので、その1件を選択する。
4. **商品リスト** が表示される。予定数に対して **受領数** を入力する（例: 1）。
5. **「確定する」** をクリックする。
6. 管理画面の **「入出庫」** に戻り、該当する **入庫** 履歴が「入庫済み」などで表示されることを確認する。

---

### ステップ 7：ロスを1件登録する

1. **「ロス / 在庫調整」** タイルをタップする。
2. **コンディション**でロケーション・日付・理由（任意）を選び、商品リストへ進む。
3. 検索またはスキャンで商品を1件追加し、ロス数量を **1** にして **「確定する」** をクリックする。
4. 管理画面の **「ロス」** を開き、履歴一覧にその1件が表示されることを確認する。

---

### ステップ 8：仕入を1件登録する

1. **「仕入 / 在庫処理」** タイルをタップする。
2. **コンディション**でロケーションと **仕入先** を選択する（マスタから選ぶか、「その他」で入力。設定で「その他」が表示されていない場合はマスタに1件以上登録しておく）。
3. 商品リストへ進み、検索またはスキャンで商品を1件追加し、**仕入数** を 1 にして **「確定する」** をクリックする。
4. 管理画面の **「仕入」** を開き、履歴一覧にその1件が表示されることを確認する。

---

### ステップ 9：発注を1件登録する

1. **「発注 / 在庫調整」** タイルをタップする。
2. **コンディション**でロケーションと **発注先** を選択する（仕入先マスタから選ぶか、「その他」で入力）。
3. 希望納品日は任意。商品リストへ進み、検索またはスキャンで商品を1件追加し、**発注数** を 1 にして **「確定する」** をクリックする。
4. 管理画面の **「発注」** を開き、履歴一覧にその1件が表示されることを確認する。

---

### ステップ 10：棚卸を1件実行する

**事前準備（管理画面）**

1. 管理画面で本アプリの **「棚卸」** を開く。
2. **「商品グループ設定」** タブで、コレクションまたは SKU から商品グループを1つ作成する（既存グループがあれば省略可）。
3. **「棚卸ID発行」** タブで、ロケーションと対象商品グループを選択し、**「棚卸ID発行」** をクリックして棚卸ID（#C0000 形式）を発行する。

**POS での操作**

4. **「棚卸 / 在庫調整」** タイルをタップする。
5. **棚卸ID一覧** から、いま発行した棚卸IDを選択する。商品グループが複数ある場合はグループを1つ選ぶ。
6. **商品リスト** が表示される。在庫数は参考表示なので、**実数** を入力する（例: 1）。商品が0件の場合は検索で1件追加してから実数を入力。
7. **「確定する」** をクリックする。
8. 管理画面の **「棚卸」** → **「履歴」** タブで、該当する棚卸IDの履歴が表示されることを確認する。

---

### ステップ 11：調整（簡易棚卸）を1件登録する

1. **「調整 / 在庫調整」** タイルをタップする。
2. **コンディション**でロケーション・日付・メモ（任意）を選び、商品リストへ進む。
3. 検索またはスキャンで商品を1件追加する。**在庫数** は参考表示、**実数** を入力する（例: 1）。
4. **「確定する」** をクリックする。
5. 管理画面の **「調整」** を開き、履歴一覧にその1件が表示されることを確認する。

---

## 3. 確認のポイント（審査側向け）

| 確認項目 | 期待される結果 |
|----------|----------------|
| 管理画面でアプリが開ける | 設定・入出庫・仕入・ロス・発注・棚卸・調整などのメニューが表示される |
| POS にタイルが表示される | 出庫・入庫・ロス・棚卸・仕入・発注・調整のタイルが並ぶ |
| 出庫 | POS で1件確定でき、管理画面「入出庫」に表示される |
| 入庫 | 出庫に対応する入庫を POS で選択・確定でき、「入出庫」に入庫済みで表示される |
| ロス | POS で1件確定でき、管理画面「ロス」に表示される |
| 仕入 | POS で1件確定でき、管理画面「仕入」に表示される |
| 発注 | POS で1件確定でき、管理画面「発注」に表示される |
| 棚卸 | 管理画面で棚卸ID発行 → POS で実数入力・確定 → 管理画面「棚卸」履歴に表示される |
| 調整 | POS で1件確定でき、管理画面「調整」に表示される |
| 履歴の詳細が開ける | 各一覧の行をクリックするとモーダルで詳細が表示される |

## 4. よくある注意点（審査・テスト時）

- **「初回は管理画面でアプリを1回開く」**  
  POS で登録した内容が履歴に正しく出るため、インストール後（または初回利用前）に、必ず1回は管理画面で本アプリを開いてください。
- **ロケーション**  
  出庫・入庫を試すには、ストアに **2つ以上のロケーション** があると分かりやすいです。1つしかない場合は、出庫元と宛先に同じロケーションを選んでも動作確認は可能です。
- **入庫**  
  入庫一覧に「未受領の出庫」が存在する場合のみ、入庫タイルで選択・確定できます。手順どおり先に出庫を1件登録してから入庫を試してください。
- **仕入・発注**  
  仕入先・発注先は設定の「仕入設定」「発注」で登録したマスタから選ぶか、「その他」で入力します。デモストアにはあらかじめ仕入先を1件以上登録しておくとスムーズです。
- **棚卸**  
  棚卸タイルでカウントするには、管理画面の「棚卸」で**商品グループ**を作成し、**棚卸IDを発行**しておく必要があります。手順 10 の事前準備を先に実行してください。

## 5. テスト手順（簡易版・コピー用）

パートナー画面の「テスト手順」欄に貼り付ける用の**短い版**です。全機能を含む完全版は **セクション 7** を参照してください。

### 日本語（短い版・出庫のみ）

```
1. デモストアに管理者としてログインする（テスト用認証情報は別途記載）。
2. 左メニュー「アプリ」から本アプリを開き、初回のみ「許可する」で認証を完了する。
3. アプリ内で「設定」が表示されることを確認したあと、左メニュー「POS」→「POSアプリ」を開く。
4. 「出庫 / 在庫処理」タイルを開き、出庫元・宛先のロケーションを選び、商品を1件追加して「確定する」をクリックする。
5. 管理画面の「アプリ」から本アプリを開き、「入出庫」メニューで履歴一覧を表示する。先ほど登録した出庫1件が表示されることを確認する。
```

### 英語（短い版・出庫のみ）

```
1. Log in to the demo store as an administrator (test credentials provided separately).
2. Open this app from the "Apps" menu and click "Install app" or "Approve" if prompted.
3. Confirm the app loads (e.g. "Settings" and "入出庫" / History in the nav), then go to POS → POS apps.
4. Open the "出庫 / 在庫処理" (Outbound) tile, select source and destination locations, add one product, and click "確定する" (Confirm).
5. Return to Admin → this app → "入出庫" (In/Out history) and verify the new outbound entry appears in the list.
```


## 8. Screencast（デモ動画）URL 用・撮影の流れ

審査用の **Screencast URL** に載せるデモ動画の**推奨の流れ**です。**2〜3分**で収め、**英語ナレーションまたは英語字幕**を付けると審査でスムーズです。

| 順 | シーン | 内容（何を映すか） | 目安時間 |
|----|--------|---------------------|----------|
| 1 | **オープニング** | アプリ名または「POS inventory app demo」など短いタイトル表示 | 5秒 |
| 2 | **管理画面ログイン** | デモストアの管理画面URLを開き、ログインする様子（パスワードは映さない／マスク推奨） | 15秒 |
| 3 | **アプリを開く（初回認証）** | 左メニュー「アプリ」→ 本アプリをクリック → 権限許可画面で「許可する」をクリック | 20秒 |
| 4 | **管理画面の確認** | アプリが開き、左ナビに「設定」「入出庫」等が表示されること。必要なら「設定」を一瞬開いてタブが並ぶ様子を見せる | 15秒 |
| 5 | **POS を開く** | 左メニュー「POS」→「POSアプリ」を開き、**タイル一覧**（出庫・入庫・ロス・棚卸・仕入・発注・調整）が並んでいる画面を 5〜10 秒映す | 15秒 |
| 6 | **出庫を1件登録** | 「出庫 / 在庫処理」タイルを開く → 出庫元・宛先を選択 → 商品を1件追加（検索 or スキャン）→「確定する」をクリック → 完了まで | 45〜60秒 |
| 7 | **管理画面で履歴確認** | 管理画面に戻る → 本アプリ →「入出庫」→ 一覧の先頭に先ほどの出庫1件があることを示す → 行をクリックしてモーダルで詳細を一瞬表示 | 25秒 |
| 8 | **クロージング** | 「Thank you for watching」またはアプリ名＋「Install from the Shopify App Store」など | 5秒 |

**合計の目安**: 約 **2分〜2分30秒**（長くても 3 分以内が望ましい）。

### 用意するときのポイント

| 項目 | 内容 |
|------|------|
| **形式** | YouTube（限定公開可）または Vimeo など、**HTTPS で再生できる URL** をパートナーの「Screencast URL」欄に入力 |
| **言語** | **英語**のナレーション、または**英語字幕**を付ける（審査で推奨） |
| **写さないもの** | パスワード・個人情報（実店舗名・メール・電話）・ブラウザのアドレスバー（必要ならぼかし） |
| **音声なしの場合** | 字幕で各シーンを短く説明（例: "Open app from Apps menu" / "Confirm outbound in POS" / "Verify history in Admin"） |

### 撮影前チェック
