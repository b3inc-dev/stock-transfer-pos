# 操作マニュアル：メニュー項目と操作内容の整理

**目的**: 入庫・出庫・仕入・発注・ロス・棚卸の「管理画面」と「アプリ（POS）側」の操作マニュアルを、サイトで別ページのコンテンツとして作成するための土台です。  
**対象読者**: マニュアル執筆者・コンテンツ担当者。

---

## 1. サイト構成イメージ（メニュー項目）

マニュアルサイトでは、次の**大メニュー**の下に「管理画面の操作」と「アプリ（POS）の操作」を分けて記載する想定です。

| 大メニュー | 説明 | 管理画面 | アプリ（POS） |
|------------|------|----------|----------------|
| **入庫** | 他店舗・倉庫から届いた商品を受け入れる | ✅ あり | ✅ あり |
| **出庫** | 他店舗・倉庫へ商品を送る | ✅ あり | ✅ あり |
| **仕入** | 仕入先から商品を受け入れ、在庫を増やす | ✅ あり | ✅ あり |
| **発注** | 仕入先へ発注（注文）する | ✅ あり | ✅ あり |
| **ロス** | 破損・紛失などで在庫を減らす | ✅ あり | ✅ あり |
| **棚卸** | 実数とシステム在庫を合わせる | ✅ あり | ✅ あり |

**共通・その他**
- **設定**: 店舗・出庫・入庫・仕入・ロスなどの共通設定（管理画面のみ）
- **在庫情報**: 在庫高・在庫変動履歴の確認（管理画面のみ）

---

## 2. 管理画面のメニューとURL

管理画面は次の**6ページ＋設定**で構成されています。

| メニュー名 | URL | 主な内容 |
|------------|-----|----------|
| 設定 | `/app/settings` | 店舗設定・出庫設定・入庫設定・仕入設定・ロス設定（タブで切り替え） |
| 在庫情報 | `/app/inventory-info` | 在庫高タブ / 在庫変動履歴タブ |
| 入出庫 | `/app/history` | 入庫・出庫の履歴一覧（統合）、フィルター、モーダル、CSV |
| 仕入 | `/app/purchase` | 仕入履歴一覧、フィルター、モーダル、CSV |
| ロス | `/app/loss` | ロス履歴一覧、フィルター、モーダル、CSV |
| 発注 | `/app/order` | 発注履歴一覧、フィルター、モーダル、CSV |
| 棚卸 | `/app/inventory-count` | 商品グループ設定タブ / 棚卸ID発行タブ / 履歴タブ |

**補足**
- 「入庫」と「出庫」の履歴は**入出庫**（`/app/history`）でまとめて管理します。
- 発注と仕入は別機能ですが、発注から仕入へ「名称引き継ぎ」（#P0000 → #P0000-1 など）があります。

---

## 3. アプリ（POS）のメニュー（タイル）

POSでは、在庫処理用に次の**タイル**が並び、タップで各機能のモーダルが開きます。

| タイル名（例） | 機能 | 主な画面の流れ |
|----------------|------|----------------|
| 出庫 / 在庫処理 | 出庫 | コンディション → 商品リスト → 確定（配送準備完了・確定する・下書き保存） |
| 入庫 / 在庫処理 | 入庫 | コンディション（入庫一覧）→ シップメント選択（複数時）→ 商品リスト → 確定 |
| ロス / 在庫調整 | ロス | コンディション → 商品リスト → 確定 |
| 棚卸 / 在庫調整 | 棚卸 | 棚卸ID一覧 → 商品グループ選択（複数時）→ 商品リスト → 確定 |
| 仕入（タイル） | 仕入 | コンディション → 商品リスト → 確定 |
| 発注（タイル） | 発注 | コンディション → 商品リスト → 確定 |

---

## 4. 機能別「操作内容」の整理

以下、**入庫・出庫・仕入・発注・ロス・棚卸**の6つについて、「管理画面でできること」と「アプリ（POS）でできること」を整理しました。マニュアルの各ページの見出し・項目のたたき台として使えます。

---

### 4.1 入庫

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **入出庫履歴の確認** | `/app/history` で入庫・出庫の履歴を一覧表示。出庫元・入庫先・ステータス・日付でフィルター可能。 |
| **履歴の詳細表示** | 一覧の行をクリックするとモーダルで開く。配送単位ごとのブロックで、予定数・入庫数・予定外入庫を表示。 |
| **配送情報の確認** | モーダル内で配送業者・配送番号・到着予定日を表示。 |
| **CSV出力** | モーダルからその履歴の明細をCSVダウンロード。出力項目は「入庫設定」タブの「入出庫履歴CSV出力項目設定」で変更可能。 |
| **入庫まわりの設定** | `/app/settings` の「入庫設定」タブで、過剰入庫の許可・予定外入庫の許可・履歴一覧の表示件数・入出庫履歴CSV出力項目を設定。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **入庫一覧の表示** | 入庫タイルを開くと、未受領/受領済みの入庫（Transfer）一覧が表示される。 |
| **入庫の選択** | 一覧から1件選ぶ。シップメントが複数ある場合は「シップメント選択」画面へ、1つの場合は商品リストへ。 |
| **商品リストでの受領** | 予定数に対して受領数を入力。全入庫・リセット・検索で商品追加が可能。画像ON/OFF・在庫更新・再読込あり。 |
| **確定の種類** | 「一部入庫」「確定する」など。過剰入庫・予定外入庫は設定で許可時のみ可能。確定後に在庫が増える。 |
| **履歴一覧** | フッターの「履歴一覧」から、これまでの入庫履歴を確認可能。 |

---

### 4.2 出庫

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **入出庫履歴の確認** | `/app/history` で出庫・入庫の履歴を一覧表示。出庫元・入庫先・ステータスでフィルター。 |
| **履歴の詳細表示** | 一覧の行をクリックでモーダル。配送単位ブロック・進捗・予定外入庫の有無を表示。 |
| **配送情報の確認** | モーダル内で配送業者・配送番号・予定日を表示。 |
| **CSV出力** | モーダルからその履歴の明細をCSVダウンロード。出力項目は入庫設定の「入出庫履歴CSV出力項目設定」で変更。 |
| **出庫まわりの設定** | `/app/settings` の「出庫設定」タブで、配送業者（carriers）・強制キャンセル許可・「その他（配送会社入力）」の表示、到着予定日ボタン設定など。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **出庫元・宛先の選択** | コンディション画面で出庫元・宛先（入庫先）ロケーションを選択。「変更」でインライン展開しロケーションを切り替え可能。 |
| **配送情報の入力** | 配送業者・配送番号・時間指定（到着予定日クイックボタンあり）。設定で「その他（配送会社入力）」を表示可。 |
| **商品リストの編集** | 商品を検索・スキャンで追加し、出庫数量を入力。画像ON/OFF・在庫更新・複製あり。 |
| **確定の種類** | 「確定する」「下書き保存」「配送準備完了にする」。確定すると在庫が減り、処理中（IN_TRANSIT）になる。 |
| **履歴一覧・編集・キャンセル** | フッターの「履歴一覧」から一覧表示。配送単位の編集・キャンセル（設定で許可時は強制キャンセル可）。 |

---

### 4.3 仕入

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **仕入履歴の確認** | `/app/purchase` で仕入履歴を一覧表示。ロケーション・ステータス・日付などでフィルター可能。 |
| **履歴の詳細表示** | 一覧の行をクリックでモーダル。商品明細・予定/仕入/超過/不足/予定外を表示。 |
| **CSV出力** | 一覧で選択した履歴の一括CSV、またはモーダルから単一履歴のCSV。出力項目は「仕入設定」の「仕入履歴CSV出力項目設定」で変更。 |
| **仕入まわりの設定** | `/app/settings` の「仕入設定」で、「その他（仕入先入力）」の表示/非表示・仕入履歴CSV出力項目を設定。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **ロケーション・仕入先の選択** | コンディションでロケーションと仕入先を選択。仕入先はマスタから選択、または「その他」で入力（設定で表示可）。 |
| **備考の入力** | 任意の備考を入力可能。 |
| **商品リストの編集** | 予定数・仕入数を入力。検索で商品追加、予定外仕入の行も追加可能。画像ON/OFF・在庫更新あり。 |
| **確定** | 確定すると在庫が増え、仕入履歴（#B0000 など）として保存。発注から引き継いだ名称（#P0000 等）で表示される場合あり。 |
| **履歴一覧** | フッターの「履歴一覧」から過去の仕入を確認。 |

---

### 4.4 発注

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **発注履歴の確認** | `/app/order` で発注履歴を一覧表示。ロケーション・発注先・ステータス・日付などでフィルター可能。 |
| **履歴の詳細表示** | 一覧の行をクリックでモーダル。商品明細・希望納品日・原価・販売価格など。商品リストモーダル内で発注先の編集が可能。 |
| **CSV出力** | 一覧で選択した履歴の一括CSV、またはモーダルから単一のCSV。出力項目は設定の「発注CSV出力項目設定」で変更。 |
| **発注まわりの設定** | `/app/settings` の「発注」関連で、希望納品日ボタンの使用・ボタン名・日数、発注CSV出力項目などを設定。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **ロケーション・発注先の選択** | コンディションでロケーションと発注先を選択。仕入先マスタまたは「その他」入力（設定で表示可）。 |
| **希望納品日の選択** | クイックボタン（1週間後・1ヶ月後など）または任意入力。設定でボタン名・日数をカスタム可能。 |
| **商品リストの編集** | 発注数量を入力。検索・スキャンで商品追加。原価・販売価格は自動取得・保存される。 |
| **確定** | 確定すると発注履歴（#P0000 形式）として保存。後から仕入で同じ名称を引き継いで仕入できる。 |
| **履歴一覧** | フッターの「履歴一覧」から過去の発注を確認。 |

---

### 4.5 ロス

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **ロス履歴の確認** | `/app/loss` でロス登録履歴を一覧表示。ロケーション・理由・ステータス・日付範囲でフィルター可能。 |
| **履歴の詳細表示** | 一覧の行をクリックでモーダル。理由・日付・商品明細・合計数量を表示。 |
| **CSV出力** | 選択した履歴の一括CSV、またはモーダルから単一のCSV。出力項目は「ロス設定」の「ロス履歴CSV出力項目設定」で変更。 |
| **ロス設定** | `/app/settings` の「ロス設定」タブで、ロス理由（破損・紛失など）の登録・編集・並び替え、「その他（理由入力）」の表示/非表示を設定。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **ロケーション・日付・理由の選択** | コンディションでロケーション・日付・理由を選択。理由は管理画面で登録した区分がボタンで表示され、「その他」で入力可（設定で表示可）。 |
| **スタッフ名の入力** | 任意でスタッフ名を入力。 |
| **商品リストの編集** | ロス数量を入力。検索・スキャンで商品追加。確定で在庫が減る。 |
| **確定** | 確定すると在庫がマイナス調整され、ロス履歴として保存。 |
| **履歴一覧・キャンセル** | フッターの「履歴一覧」から一覧表示。キャンセルすると在庫を戻す処理が実行される。 |

---

### 4.6 棚卸

#### 管理画面の操作内容

| 項目 | 内容 |
|------|------|
| **商品グループ設定** | `/app/inventory-count` の「商品グループ設定」タブ。コレクションから作成・SKU選択から作成・CSVで一括登録の3方式でグループを作成・編集。 |
| **棚卸IDの発行** | 「棚卸ID発行」タブでロケーションと対象商品グループを選択し、「棚卸ID発行」で #C0000 形式の棚卸IDを発行。 |
| **棚卸履歴の確認** | 「履歴」タブで棚卸ID・ロケーション・商品グループ・ステータス・日付でフィルターし、一覧・モーダルで詳細・CSV出力。 |
| **棚卸まわりの設定** | `/app/settings` の「棚卸」関連で、棚卸履歴CSV出力項目を設定。 |

#### アプリ（POS）の操作内容

| 項目 | 内容 |
|------|------|
| **棚卸ID一覧の表示** | 棚卸タイルを開くと、未完了/完了済みの棚卸ID一覧が表示される。 |
| **棚卸の選択** | 一覧から1件選択。商品グループが1つなら商品リストへ、複数なら「商品グループ選択」画面を経由。 |
| **商品リストでの実数入力** | 現在在庫数は参考表示、実数を入力。全数量反映・リセット・検索で追加。在庫レベルがないSKUはスキャン/検索で追加可能。 |
| **確定** | 確定すると在庫が「実数」に合わせて絶対値で更新され、棚卸履歴として保存。 |
| **履歴一覧** | フッターなどから棚卸履歴を確認可能。 |

## 5. 設定・在庫情報（共通）

マニュアルで「入庫・出庫・仕入・発注・ロス・棚卸」以外に独立したページやセクションにする場合の整理です。

| テーマ | 管理画面の操作内容 | アプリ（POS） |
|--------|--------------------|----------------|
| **設定** | `/app/settings`。タブ：アプリ設定（店舗・表示件数）、出庫設定、入庫設定、仕入設定、ロス設定。各機能の許可やCSV出力項目・希望納品日/到着予定日ボタンなど。 | なし（管理画面のみ） |
| **在庫情報** | `/app/inventory-info`。在庫高タブ（日付・ロケーションで表示・本日集計・CSV）、在庫変動履歴タブ（期間・ロケーション・商品・アクティビティでフィルター、CSV）。 | なし（管理画面のみ） |
