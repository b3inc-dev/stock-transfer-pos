# 管理画面：導入（TOP）・料金プラン の要件・UI設計

**目的**: 参考アプリ（CRM PLUS on LINE 型）をベースに、**導入ページ（ホーム）** と **料金プランページ（プラン選択＋プラン別機能の記載）** の項目・UI を要件としてまとめる。  
**対象**: 公開アプリ向け管理画面。カスタムアプリのときは表示を簡略化またはスキップ可能とする。

---

## 1. 全体のレイアウト方針

- **カードベース**: 各ブロックは白背景のカードで区切り、余白をとる。
- **2カラム（導入ページ）**: 左＝導入ステップ（メイン）、右＝サマリー（現在のプラン・ロケーション数など）。
- **1カラム（料金プラン）**: 上から「プラン選択」→「プラン別機能の紹介」の順。必要に応じてセクション見出しで分割。

---

## 2. 導入ページ（ホーム / TOP）の要件・UI

**URL**: `/app`  
**参照**: 参考1枚目（左：設定ステップのカード、右：サマリーカード）

### 2.1 ページヘッダー

| 項目 | 内容 |
|------|------|
| **タイトル** | アプリ名＋短いキャッチ（例: 「〇〇 - POSで在庫を一元管理」）。またはアプリ名のみ。 |
| **右端** | メニューアイコン（三点リーダー等）は任意。必要なら「ヘルプ」「サポート」へのリンク。 |

### 2.2 左カラム：はじめての設定（導入ステップ）

**目的**: 番号付きで「何を設定するか」の順番を示し、各ステップにアクション（ボタン・リンク）を付ける。

| # | ステップのタイトル | 説明文（1〜2行） | アクション |
|---|--------------------|------------------|------------|
| 1 | 料金プランを選択する | 未選択の場合のみ表示。「Lite または Pro を選択し、利用を開始しましょう。」 | ボタン「料金プランを選択する」→ `/app/plan` へ遷移 |
| 2 | 設定でロケーション等を確認する | 「出庫元・入庫先に使うロケーションや、出庫・入庫の初期設定を行います。」 | ボタン「設定を開く」→ `/app/settings` へ遷移 |
| 3 | 入出庫の使い方を確認する | 「POS で出庫・入庫を使う前に、管理画面で入出庫履歴の見方を確認しましょう。」 | ボタン「入出庫を開く」→ `/app/history` へ遷移 |
| 4 | （Pro の場合）仕入・ロス・棚卸・発注を使う | 「仕入・ロス・棚卸・発注は Pro プランで利用できます。各メニューから設定や履歴を確認できます。」 | ボタン「仕入を開く」等、該当メニューへのリンク（Pro のときのみ表示） |

**UI 仕様**

- 各ステップは**1枚のカード**。カード内：タイトル（見出し）→ 説明文 → ボタン（またはテキストリンク＋外部リンクアイコン）。
- ボタンは 1 ステップ 1 つ。Primary または Secondary のどちらかに統一。
- プラン未選択時はステップ 1 を強調（枠線・バッジ「未完了」等）してもよい。
- **カスタム**のときは「料金プラン」ステップを非表示にし、2〜4 のみ表示するか、文言を「設定からはじめましょう」に変更。

### 2.3 右カラム：サマリー（ステータスカード）

**目的**: 現在のプラン・ロケーション数などを一目で把握できるようにする。

| カード | 表示内容 | 備考 |
|--------|----------|------|
| **現在の料金プラン** | 表示例: 「Lite（7日間トライアル中）」／「Pro」／「プランが選択されていません」。有料プランなら「$19/月」等の目安を併記可。 | プラン未選択時は「料金プラン」へのリンクを同カード内に表示。Lite のときは「アップグレードして全機能を使いましょう」等の短文＋「料金プラン」リンクを出してもよい。 |
| **ロケーション数** | 表示例: 「3」＋「/ 〇〇」（上限がある場合）。または「3 ロケーション」のみ。 | Shopify のショップ情報（locations）から取得。 |
| **（任意）利用状況** | 例: 「直近30日の出庫件数」「入庫件数」など。なくても可。 | 初期リリースでは省略し、余裕があれば追加。 |

**UI 仕様**

- 各項目は**1枚のカード**。見出し＋数値（または短文）。情報アイコン＋ツールチップは任意。
- 右カラムは左より狭く（例: 左 2/3・右 1/3）、レスポンシブで狭い画面では右を下に回す。

### 2.4 フッター（任意）

- 例: 「お問い合わせは〇〇サポート窓口まで」＋サポートURL。参考1枚目と同様の位置で問題なし。

## 3. 料金プランページの要件・UI

**URL**: `/app/plan`  
**参照**: 参考2枚目（プランカード一覧）、3枚目（プラン別機能）、4枚目（プランタグ・使用量）

### 3.1 ページ構成（上から順）

1. **プラン選択**（3.2）… Lite / Pro のカードと CTA
2. **プラン別機能の紹介**（3.3）… 「全プランで利用可能」「Pro で利用可能」のセクション

### 3.2 プラン選択セクション

**見出し**: 「料金プラン」

**表示する情報（ヘッダー付近）**

- 右端など: 「ロケーション数: 〇」を表示すると、プラン料金がロケーション数に連動している場合に分かりやすい（任意）。

**プランカード（Lite / Pro）**

| 項目 | Lite | Pro |
|------|------|-----|
| **プラン名** | Lite | Pro |
| **料金** | 3ロケーション: $20 / 10ロケーション: $40 / 10以上: 1ロケーションあたり$4 | 3ロケーション: $60 / 10ロケーション: $120 / 10以上: 1ロケーションあたり$12 |
| **トライアル** | 7日間無料 | 14日間無料 |
| **機能の要約** | 入出庫（POS・管理画面）、入出庫履歴・CSV | 在庫情報・入出庫・仕入・ロス・発注・棚卸・調整（全機能） |
| **ボタン** | 「このプランを選択する」→ Shopify のプラン選択ページへ遷移 | 同上。**現在のプランが Pro のとき**は「このプランを利用中」と表示し、ボタンは無効またはリンクを「請求の変更は Shopify から」に変更。 |

**UI 仕様**

- 各プランを**1枚のカード**。横並び（2列）または縦並び。**現在選択中のプラン**は太枠または背景色で強調。
- 「このプランを選択する」は Shopify の `…/pricing_plans` へ遷移。遷移先で実際の選択・承認を行う。
- プラン未選択時は両方のカードに「このプランを選択する」を表示。選択済みの場合は「利用中」と「選択する」を出し分ける。
- **ダウングレード不可**などの理由で変更できない場合は、グレーアウト＋「〇〇のため変更できません」等の短いメッセージを表示（任意）。

### 3.3 プラン別機能の紹介セクション

**目的**: 「どのプランで何が使えるか」を機能単位で説明する。参考3枚目（機能紹介の段階表示）に合わせる。

**見出し例**

- 「全てのプランで利用可能な機能」
- 「Pro プランで利用可能な機能」

**セクション1: 全てのプランで利用可能な機能**

- **対象**: 入出庫（出庫・入庫）、入出庫履歴・フィルター・CSV。
- **表示**: 機能ごとに**カード**（アイコン＋短い説明文）。例:
  - 「出庫」… POS で出庫登録。管理画面で履歴・CSV。
  - 「入庫」… POS で入庫受領。管理画面で履歴・CSV。
  - 「入出庫履歴」… フィルター・ページネーション・CSV 出力。
- カードはグリッド（2〜3列）。アイコンはシンプルなイラストまたは Polaris Icon。

**セクション2: Pro プランで利用可能な機能**

- **対象**: 在庫情報、仕入、ロス、発注、棚卸、調整。
- **表示**: 同様に機能カードで列挙。各カードに「Pro」バッジまたはタグ「Pro プランで利用可能」を付ける。
  - 「在庫情報」… 在庫高・在庫変動履歴。
  - 「仕入」… 仕入登録・履歴・CSV。
  - 「ロス」… ロス登録・履歴・CSV。
  - 「発注」… 発注・履歴・CSV。
  - 「棚卸」… 棚卸 ID 発行・カウント・履歴。
  - 「調整」… 簡易棚卸（調整）・履歴。
- 「アップグレードして全機能を使いましょう」＋「料金プランで Pro を選択する」リンクをセクション末尾に置いてもよい。

**UI 仕様**

- セクション見出しは H2。その下に説明文 1 行（任意）、続けてカードグリッド。
- カードはホバー時のみ背景色を変える等、シンプルに。参考3枚目の「CVR」ラベルのような付加情報は、本アプリでは不要なら省略。

### 3.4 （任意）使用量・追加料金の表示

- 参考4枚目の「使用量に基づく料金」のように、**ロケーション数に応じた料金**を説明する短文を、プラン選択セクションの下に 1 ブロックとして入れてもよい。
- 例: 「料金はロケーション数に応じて変わります。詳細はプラン選択画面でご確認ください。」

## 4. データ・API の前提

| 画面 | 必要なデータ | 取得元 |
|------|----------------|--------|
| 導入（TOP） | 現在のプラン、ロケーション数 | `GET /api/shop-plan`、Shopify Admin API（locations） |
| 料金プラン | 現在のプラン、ロケーション数 | 同上。プラン一覧の文言・料金は固定または設定から。 |

---

## 5. カスタムアプリ時の扱い

- **導入ページ**: 「料金プラン」ステップを非表示。「現在の料金プラン」カードは「全機能をご利用いただけます」等の文言に差し替え。ロケーション数は同じく表示してよい。
- **料金プランページ**: 表示しない（ナビから非表示）、または表示するが「このアプリでは全機能が利用可能です」とだけ表示し、プラン選択ボタンは出さない。

---

## 6. 実装時のファイル・ルート対応

| 画面 | ルート | 備考 |
|------|--------|------|
| 導入（TOP） | `app._index.tsx`（`/app`） | 新規にホーム用の loader・UI を実装。設定は re-export しない。 |
| 設定 | `app.settings.tsx`（`/app/settings`） | 既存。ナビから「設定」で `/app/settings` に遷移。 |
| 料金プラン | `app.plan.tsx`（`/app/plan`） | 新規作成。プラン選択＋プラン別機能の 2 ブロック。 |

**料金プラン画面の「プランを選択する」リンク**: Shopify のプラン選択ページの URL は、環境変数 **`SHOPIFY_APP_HANDLE`**（パートナーダッシュボードのアプリハンドル）で組み立てています。未設定時は `app` をフォールバックに使用。本番ではパートナーで確認したアプリハンドルを設定してください。
